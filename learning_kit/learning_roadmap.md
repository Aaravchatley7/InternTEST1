# Learning Roadmap

## Goal

Enable a new BHIV engineer to progress from repository setup to ecosystem contribution.

---

# Level 1 — Repository Setup

Objective:

Run the platform locally.

Learn:

- Installation
- Environment Setup
- Dependency Management
- FastAPI Startup

Tasks:

- Install dependencies
- Configure .env
- Run application
- Run tests

Success Criteria:

System runs successfully.

---

# Level 2 — Understanding The Pipeline

Objective:

Understand how requests move through the system.

Learn:

- Input Layer
- Extraction Layer
- Validation Layer
- Confidence Layer
- Evidence Layer

Tasks:

- Read architecture guide
- Follow request flow
- Review logs

Success Criteria:

Can explain the end-to-end workflow.

---

# Level 3 — Modifying Existing Modules

Objective:

Safely modify platform behavior.

Learn:

- Validation Rules
- Confidence Weights
- OCR Improvements
- Evidence Generation

Tasks:

- Modify confidence weights
- Add validation rule
- Update evidence output

Success Criteria:

Can extend existing modules safely.

---

# Level 4 — Building New Capabilities

Objective:

Create new platform capabilities.

Learn:

- Capability Registry
- SDK Interfaces
- Document Handlers
- Replay Integration

Tasks:

- Add Passport Support
- Create New Handler
- Register Capability

Success Criteria:

Can add new document types.

---

# Level 5 — Ecosystem Contribution

Objective:

Contribute reusable capabilities to BHIV.

Learn:

- Versioning
- Provenance
- Capability Registration
- Integration Patterns

Tasks:

- Create reusable capability
- Document capability
- Publish integration guide

Success Criteria:

Capability can be reused by another BHIV team.

# Final Outcome

A developer completing this roadmap should be able to:

- Understand the repository
- Extend the platform
- Create new document handlers
- Build new validators
- Integrate new OCR providers
- Contribute reusable BHIV capabilities
